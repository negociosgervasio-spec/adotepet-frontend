# 🐾 Frontend - Sistema de Adoção de Pets

Este projeto é o **frontend** do sistema de adoção de pets.  
Ele foi desenvolvido em **React** com **Vite** e integra com o backend para permitir cadastro de pets, gerenciamento de adoções e autenticação de usuários.

---

## 🚀 Funcionalidades

- Interface moderna e responsiva com **TailwindCSS**
- Navegação com **React Router**
- Gerenciamento de estado e requisições com **React Query**
- Animações com **Framer Motion**
- Notificações com **Sonner**
- Ícones com **Lucide React**
- Suporte a autenticação e consumo da API do backend

---

## 🛠️ Tecnologias

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [TailwindCSS](https://tailwindcss.com/)
- [React Router](https://reactrouter.com/)
- [Sonner](https://sonner.emilkowal.ski/)
- [Lucide React](https://lucide.dev/)
